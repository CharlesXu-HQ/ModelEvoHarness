# Reco-papers component coverage

This extension audits **115 PDF entries** at Reco-papers commit `2c617a1659c38f60848c051b377f3faef5df831f`, adding **25 component IDs / 50 framework entries**. The library now has **69 method cards**, **25 family guides** and **140 PyTorch/TensorFlow entries**, including the generic TwoTower pair.

Coverage means a portable model, objective or matrix selector with explicit tensor inputs. It does not mean benchmark replication. Large-model training, graph/index construction, production data reconstruction, simulators, bandit policies and deployment systems are excluded where they are the paper's primary contribution. Existing HSTU is retained; no new large-model components are added. A generative paper is not automatically a large-model paper: each disposition records the actual boundary.

Disposition counts: **24 added_core**, **18 existing_core**, **14 shared_mechanism**, **58 excluded**, **1 duplicate**. A shared mechanism is not a dedicated paper implementation; duplicate Image Matters PDFs share one component.

## Agent integration

`load_catalog()` includes the complete `paper_inventory`, method cards and source provenance. `method_applicability()` checks family and method prerequisites. Each method maps to one structural pattern, a local family guide, both framework symbols and a concrete output/training contract. Relevant loss components also map to training patterns. `model_api()` and `read_references()` expose those contracts alongside the code; source hashes continue to participate in the existing implementation ledger. `catalog-check` validates the cross-links and reports disposition counts.

```python
from model_evo_harness import load_catalog, model_api, read_references, paper_coverage_report

catalog = load_catalog()
print(paper_coverage_report(catalog))
api = model_api(catalog, framework="tensorflow", method_ids={"pal", "mmrec"})
source = read_references(catalog, {"framework": "tensorflow", "method_ids": ["pal", "mmrec"]})
```

Each extracted module depends only on its framework and Python standard library. The caller owns its backbone, input adapters and training loop. TensorFlow entries follow the repository's current Keras API; **they are not TensorFlow 1.15 snippets**. This extension does not change the separate PDF-to-TF1.15 skill.

## Source and license decisions

GitHub implementations were inspected for reusable mechanisms and checked for redistribution terms. The DICE masked objective was adapted under MIT, with the notice preserved in both modules and [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md). Other new code is independently written from paper mechanisms; consulted repositories and immutable revisions appear in the method cards. GPL CDL code and sources without a verified license (including the author FNN, MetaEmbedding and MM-Rec repositories) were not transplanted. No paper PDF, dataset or pretrained weight is bundled.
