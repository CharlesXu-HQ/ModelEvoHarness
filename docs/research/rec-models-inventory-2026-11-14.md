## Provenance and reuse constraints

This is a mixed-origin collection, not evidence of one coherent upstream package or repository-wide license. The full tree has no root license; the only license-named blob is `DSIN/LICENSE`. [DSIN/README.md:44](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/DSIN/README.md#L44) declares Apache-2, consistent with the additionally inspected [DSIN/LICENSE:1](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/DSIN/LICENSE#L1).

Their `fuxictr_version.py` files impose minimum strings rather than lock an exact dependency revision. DSIN's [requirements.txt:1](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/DSIN/requirements.txt#L1) pins DeepCTR and an old TensorFlow GPU release. DSSM imports DeepCTR and DeepMatch. These dependencies are not bundled model implementations.

The FFM notebook carries Microsoft copyright and an MIT statement in [its first cell](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/FFM/fm_deep_dive.ipynb#L7). [GBDT+LR-Demo/readme.md:1](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/GBDT%2BLR-Demo/readme.md#L1) explicitly names a copied source repository. [EGES README:3](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/eges/eges_1_dgl/README.md#L3) names a reference implementation; [FNN Theano README:3](https://github.com/lmxhappy/rec_models/blob/966f5f66f07da78d16f16d44a3978be7235fd7a9/fnn/fnn_theno/README.md#L3) points to the authors' later work. ## Source-quality findings relevant to adoption

- **MLR training contaminates its test evaluation.** `mlr.py:47–48` feeds the test batch while fetching `train_op`; line 27 also supplies an already mixed probability as `logits` to a logits loss. This is direct source evidence, not an executed failure. Use Harness's native core and an independently controlled evaluator.
- **GBDT+LR uses the training labels as test labels.** `GBDT_LR.py:22–24` assigns `y_test = df_train['target']`. Reported evaluation from that script cannot be taken as a reliable baseline without correction.
